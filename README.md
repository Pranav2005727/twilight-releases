# Twilight

### [⬇ Download Twilight (latest)](https://github.com/Pranav2005727/twilight-releases/releases/latest/download/Twilight.exe)

1. Download `Twilight.exe` from the link above and put it somewhere you can write to, like your
   Desktop or Documents. Program Files won't work.
2. Open it. Windows may warn that it's from an unknown publisher: click **More info** → **Run anyway**.
3. The first time, it shows **Not authorised** with a code. Click **Copy code** and send the code to
   the owner. Once they've added you, click **Check again**.

Twilight updates itself. When a new version is out, it asks when you open it.
